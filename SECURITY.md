# Security

This project is an initial development foundation, not a production security
certification. Review boundaries include untrusted protocol inputs, fixed-source
HTTP, archive parsing, lockfile privacy, permanent storage, TLS, and network isolation.

Use GitHub's private vulnerability reporting for this repository if enabled.
If unavailable, contact a maintainer privately to establish a confidential channel
before transmitting sensitive details. Do not post undisclosed vulnerabilities,
credentials, or private lockfiles in public issues. This repository does not promise
a response deadline or long-term support policy. Do not request CVEs or publish
advisories without explicit maintainer authorization.
